# RedisM 文档中心

欢迎来到RedisM v1.1.0的文档中心！

## 📚 核心功能

### ✅ 主要特性
- **数据库一致性**: 彻底解决数据库切换问题，确保所有操作在正确数据库中执行
- **自适应对话框**: 所有Add/Edit对话框支持真正的自适应高度调整
- **安全认证**: 密码查看需要系统认证，保护敏感信息
- **JSON语法高亮**: 全面的JSON彩色语法高亮显示
- **智能重连**: 连接断开时自动重连，操作无缝继续
- **实时统计**: 结构化数据显示总数统计和过滤结果

## 📖 v1.1.0 新功能详解

### 🔧 数据库一致性保障
- **集中管理**: 通过`get_redis_client()`统一确保数据库状态
- **操作同步**: 所有Redis操作自动在正确数据库中执行
- **状态维护**: 防止连接池重用导致的数据库切换问题
- **问题修复**: 解决Add New Key、删除key等操作的数据库切换问题

### 🎨 自适应对话框完善
- **统一体验**: 所有Add对话框转换为SimpleDialog架构
- **真正自适应**: 文本区域随窗口大小实时调整
- **布局优化**: 固定区域和可扩展区域的合理分配
- **用户友好**: 提供一致的编辑体验

### 🔐 安全认证增强
- **密码保护**: Redis连接密码查看需要系统认证
- **系统集成**: 使用macOS系统密码验证机制
- **安全可视**: 👁图标提供直观的密码查看入口
- **权限控制**: 只有通过认证才能查看敏感信息

### ✨ JSON语法高亮
- **彩色显示**: 字符串、键、数字、布尔值、null值的不同颜色
- **实时高亮**: 编辑过程中实时应用语法高亮
- **统一方案**: 所有JSON文本区域使用一致的颜色方案
- **可读性提升**: 显著提升JSON数据的可读性

### 📊 过滤和统计优化
- **固定布局**: 过滤文本框固定25字符宽度
- **实时统计**: 显示"Total: X fields/items/members"
- **准确计数**: 修复初始统计显示问题
- **用户体验**: 提供即时和准确的数据统计

## 🛠 技术架构

### 核心改进
- **数据库管理**: `get_redis_client()`方法确保每次操作都在正确数据库中
- **对话框架构**: SimpleDialog提供真正的自适应布局管理
- **安全机制**: 系统级密码验证保护敏感信息
- **语法高亮**: 基于正则表达式的JSON语法高亮引擎
- **状态同步**: 连接池和应用状态的完全同步

## 💡 使用建议

### 最佳实践
1. **数据库操作**: 放心在任何数据库中操作，系统确保一致性
2. **对话框使用**: 充分利用自适应高度，调整窗口大小获得最佳体验
