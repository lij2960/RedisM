## 📖 功能亮点

### 🔧 数据库一致性保障 (v1.1.0+)
- **集中管理**: 通过`get_redis_client()`统一确保数据库状态
- **操作同步**: 所有Redis操作自动在正确数据库中执行
- **状态维护**: 防止连接池重用导致的数据库切换问题
- **问题修复**: 解决Add New Key、删除key等操作的数据库切换问题

### 🎨 自适应对话框 (v1.1.0+)
- **统一体验**: 所有Add对话框转换为SimpleDialog架构
- **真正自适应**: 文本区域随窗口大小实时调整
- **布局优化**: 固定区域和可扩展区域的合理分配
- **用户友好**: 提供一致的编辑体验

### 🔐 安全认证 (v1.1.0+)
- **密码保护**: Redis连接密码查看需要系统认证
- **系统集成**: 使用macOS系统密码验证机制
- **安全可视**: 👁图标提供直观的密码查看入口
- **权限控制**: 只有通过认证才能查看敏感信息

### 🔄 智能重连 (v1.1.1+)
- **异步重连**: 连接断开时后台自动重连，不阻塞UI
- **超时设置**: 5秒连接超时，避免长时间等待
- **状态反馈**: 重连过程中显示清晰的状态信息
- **操作恢复**: 重连成功后自动继续之前的操作

### 🆕 PHP Serialize支持 (v1.1.2+)
- **Format PHP**: 解析PHP序列化数据为可读JSON格式
- **Minify PHP**: 智能转换JSON/PHP格式
- **智能检测**: 自动识别输入格式
- **往返转换**: 支持PHP ↔ JSON ↔ PHP无缝转换
- **全面集成**: 所有编辑对话框都支持PHP序列化操作

详细使用说明请查看 [PHP Serialize使用指南](PHP_SERIALIZE_USAGE.md)

## 💡 使用建议

### 最佳实践
1. **数据库操作**: 放心在任何数据库中操作，系统确保一致性
2. **对话框使用**: 充分利用自适应高度，调整窗口大小获得最佳体验
3. **密码管理**: 使用👁按钮安全查看已保存的密码
4. **JSON编辑**: 利用语法高亮提升JSON数据的编辑效率
5. **PHP数据**: 使用Format PHP查看，编辑后用Minify PHP转回
6. **连接稳定**: 连接断开时等待自动重连，无需手动干预

### 故障排除
- **数据库问题**: 系统自动确保操作在正确数据库中，无需手动干预
- **对话框问题**: 尝试调整窗口大小触发自适应布局
- **密码查看**: 确保系统密码正确，认证后即可查看
- **语法高亮**: JSON格式错误时高亮可能不正确，请检查JSON语法
- **PHP Serialize**: 确保输入的是有效的PHP序列化或JSON格式
- **连接问题**: 等待自动重连，查看状态栏的重连提示
- **打包问题**: 查看[重新打包指南](REBUILD_INSTRUCTIONS.md)
