## 📖 v1.0.4 新功能详解

### 🔄 智能自动重连
- **自动检测**: 每次操作前自动检测连接状态
- **智能重连**: 连接断开时自动尝试重连
- **无缝操作**: 重连成功后自动继续原操作
- **状态反馈**: 实时显示重连状态和操作结果

### 🗄️ 数据库切换优化
- **问题解决**: 彻底解决数据库切换时显示旧数据的问题
- **专用客户端**: 为每个数据库创建专用Redis客户端
- **连接池管理**: 优化连接池状态管理
- **实时更新**: 切换数据库后键列表立即更新

### 🎨 双面板服务器信息
- **左面板**: 基本信息、运行时信息、内存信息
- **右面板**: 统计信息、数据库信息表格
- **空间优化**: 移除多余边距，最大化屏幕利用率
- **表格显示**: 数据库信息以表格形式展示，当前数据库高亮

## 🛠 技术架构

### 项目结构
```
RedisM/
├── src/                    # 源代码目录
│   ├── config.py          # 应用配置和常量 (v1.0.4)
│   ├── main.py            # 应用程序入口点
│   ├── dialogs/           # 对话框组件
│   │   ├── simple_dialog.py    # 自适应对话框基类
│   │   ├── search_mixin.py     # 搜索功能混入类
│   │   └── key_dialogs.py      # 键编辑对话框
│   ├── redis/             # Redis操作模块
│   │   ├── connection.py       # 连接管理 (增强重连功能)
│   │   └── operations.py       # 数据操作
│   ├── ui/                # 用户界面组件
│   │   ├── key_manager.py      # 键管理器 (双面板布局)
│   │   └── left_panel.py       # 左侧面板 (数据库切换优化)
│   └── utils/             # 工具函数
├── docs/                  # 文档目录 (精简)
└── main.py               # 主程序入口
```
